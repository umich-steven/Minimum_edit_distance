# Test cases for a minimum edit distance (Levenshtein) implementation.
#
# FORMAT   source|target|d_sub1|d_sub2
#   d_sub1 = distance with insert=1, delete=1, substitute=1  (standard Levenshtein)
#   d_sub2 = distance with insert=1, delete=1, substitute=2  (Jurafsky & Martin variant,
#            where a substitution is treated as a delete plus an insert)
#
# PARSING NOTES
#   - Lines starting with '#' are comments; blank lines are separators. Skip both.
#   - Split on the FIRST 3 '|' characters only. No string below contains a '|'.
#   - Do NOT strip the fields: empty strings and leading spaces are deliberate
#     test cases (an empty field means the empty string "").
#   - Split into 4 fields, e.g. in Python:
#         src, tgt, d1, d2 = line.rstrip(chr(10)).split('|')
#
# All expected values were computed with a reference DP implementation.
# Every pair also appears with its arguments in one order only -- distance is
# symmetric, so d(source, target) == d(target, source) is worth asserting too.
